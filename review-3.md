# ¿Qué es mi producto y para qué sirve?

Mi product es un servidor de lista de tareas construido con Node.js y Express. Es un programa que corre en una computadora o servidor y se encarga de guardar, organizar y entregar tareas cuando una aplicación se lo pide.

Su propósito es ayudar a las personas a gestionar sus actividades del día a día, ya sea para uso personal, para estudios o dentro de un equipo de trabajo. La idea es que siempre tengas tus pendientes disponibles, ordenados y accesibles desde cualquier aplicación que se conecte a este servidor.

# ¿Cuáles son las funcionalidades más importantes y por qué los usuarios las usarían?

Las funcionalidades más importantes son:

- Consultar la lista de tareas : 
  Los usuarios pueden ver todas las tareas guardadas, lo que les permite tener control de sus pendientes

- Agregar nuevas tareas  :
  Permite registrar nuevas actividades fácilmente, ayudando a organizar el trabajo o estudio.

- Manejo de datos en formato JSON  :
  Esto permite que otras aplicaciones puedan conectarse al servidor sin problemas.

- Servidor rápido y ligero  :
  El sistema responde rápidamente, lo que mejora la experiencia del usuario.

Los usuarios usarían este sistema porque les permite mantener ordenadas sus actividades y acceder a ellas de forma rápida y segura

# ¿Qué tecnologías usaste y por qué?

Para desarrollar este producto utilicé:

- Node.js  
  Porque permite crear servidores rápidos y eficientes.

- Express  
  Porque facilita la creación de rutas y el manejo de solicitudes de forma sencilla.

- JavaScript  
  Porque es un lenguaje muy usado en el desarrollo web y permite integrar fácilmente el servidor con otras aplicaciones.

Estas tecnologías fueron elegidas porque son modernas, confiables y muy utilizadas en el desarrollo de aplicaciones actuales
