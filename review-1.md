# ¿Qué es mi producto y para qué sirve?

Mi producto es Task List Server el cual es un servidor que permite organizar tareas de manera sencilla y eficiente. Su objetivo principal es ayudar a personas y equipos a gestionar sus actividades diarias, mantener el orden y poder aumentar la productividad.

Mi producto permite almacenar tareas para consultarlas y administrarlas desde cualquier aplicación conectada, lo que facilita el seguimiento del trabajo en tiempo real.

---

# ¿Cuáles son las funcionalidades más importantes y por qué los usuarios las usarían?

Las estas  funcionalidades ayudan a mejorar la organización personal y laboral, reducen el estrés y aumentan la productividad, estas son:

• Crear nuevas tareas
Los usuarios podrán agregar tareas fácilmente, lo que les permite planificar su día o sus proyectos.

• Poder consultar la lista de tareas completas
Concede visualizar todas las actividades registradas, ayudando a tener claridad sobre lo que está pendiente.

• Actualizar las tareas
Si una actividad cambia o se completa, se puede modificar para mantener la información actualizada.

• Eliminar tareas
Cuando una tarea ya no se considera necesaria se puede eliminar.

# ¿Qué tecnologías usaste y por qué?

La tecnología que se utilizó fue Node.js y Express para construir el servidor.

Node.js permite crear aplicaciones rápidas y eficientes y express facilita la creación de rutas y la gestión de solicitudes de manera sencilla, lo que tienen estas tecnologías es que son confiables, modernas y utilizadas en el desarrollo de aplicaciones web.
